# Sample files: all synthetic

Every file here is made up for testing. None of it comes from a real school, officer, child or photo.

| Folder | What it is | What the app does with it |
|---|---|---|
| `block-exports/` | The 7 messy exports of the demo block (Kesli, 110 schools), generated by the app's own seed | Upload all 7 in step 1: 548 rows, 9 data problems, 110 codes fixed, 4 flags |
| `guardrails/student_level_sample.csv` | **A deliberately forbidden file.** One synthetic student row: "Asha Kumari" is a made-up name, and `123412341234` cannot be a real Aadhaar number, since those never start with 0 or 1 | Refused: student-level data never enters the block file |
| `guardrails/messy_headers.csv` | Two unknown column names | The app asks you to map the columns |
| `photos/` | Drawn classroom scenes, not photographs; no real children | The group scene passes; the single-child close-up and the blurry scene are refused |

See [`EVALUATOR_GUIDE.md`](../../EVALUATOR_GUIDE.md) for where to use each file.
